# ORIGAMI

ORIGAMI identifies the cosmic-web morphology of particles in N-body
simulations. Each particle is classified as a void, wall, filament, or halo
particle by counting the number of orthogonal axes along which it has
undergone shell-crossing
([Falck, Neyrinck & Szalay 2012](https://ui.adsabs.harvard.edu/abs/2012ApJ...754..126F)).
